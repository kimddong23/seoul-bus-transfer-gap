# seoul-bus-transfer-gap: 서울 대중교통 카드 유형별 환승시간 차이 분석

- 참가 대회명: AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전
- 주제: 같은 정류장, 같은 시간대, 더 긴 환승: 공개 교통카드 기록으로 찾은 장애인·경로 카드의 버스 환승 격차와 매달 점검할 정류장

서울시 공개 교통카드 환승 기록으로 장애인·경로 카드와 일반 카드의 환승시간을 같은 경로·같은 날·같은 시간대 안에서 비교하는 분석 코드. 차이가 크고 기록이 많은 경로를 현장 확인 우선 후보로 고름

## 개요

- 서울 열린데이터광장의 「서울시 정류장별 사용자유형별 환승 승객수 및 환승시간 정보」는 하차→승차 정류장 쌍·날짜·1시간 시간대별로 카드 유형(일반·어린이·청소년·경로·장애인)의 환승 건수와 평균 환승시간을 공개함
- 원자료 한 행 안에서 대상 카드(장애인·경로)와 일반 카드의 평균 환승시간 차이를 계산함. 같은 행이므로 경로·날짜·시간대 조건이 같음
- 2026년 9월로 차이가 크고 기록이 많은 경로를 후보로 고르고 2026년 8월·10월 1\~13일로 재현을 확인함
- 어린이·청소년 카드는 카드 유형만 달라도 기록상 차이가 생기는지 보는 대조군으로 같이 계산함
- 지표 정의는 카드 유형 간 차이를 계산하기 전에 `docs/kpi_registry.yaml`로 고정함. 결과를 본 뒤 더한 분석은 '추가 점검(사전등록 외)'으로 구분함
- 공모전에 제출한 분석 보고서(별도 문서)의 그림·수치는 이 저장소의 `outputs/`에서 나옴

## 주요 결과

- 사전등록 1차 지표 A1(9월, 경로유형 전체)은 장애인 카드 0.28분(95% 구간 0.25\~0.31), 경로 카드 -0.33분(-0.38\~-0.29)임. 경로 카드가 음수인 것은 가중치의 약 20%를 차지하는 역→역 환승이 -3.22분으로 방향이 반대이기 때문임(장애인 카드는 역→역 -2.63분, 가중치 약 3%) (`outputs/tables/kpi_results.csv`)
- 9월 버스→버스 환승의 평균 차이(대상 카드 − 일반 카드)는 장애인 카드 0.36분(0.33\~0.39), 경로 카드 0.40분(0.37\~0.43)임. 버스→버스 값은 사전등록 두 층(같은 정류장·다른 정류장)을 합친 층의 값임(`docs/kpi_changelog.md` #9) (`outputs/tables/a1_all.csv`)
- 버스→버스 차이는 8월 장애인 카드 0.35분·경로 카드 0.36분, 10월 1\~13일 0.39분·0.30분임. 대조군인 어린이·청소년 카드는 세 기간 모두 -0.11\~0.03분으로 0 근처이거나 음수임(청소년 카드 9월 -0.11분은 95% 구간 -0.14\~-0.07로 0보다 작음) (`a1_all.csv`)
- 출근 시간(07\~09시) 차이가 가장 큼. 장애인 카드 0.54분(일반 카드 대비 11.7%), 경로 카드 0.60분(12.3%)임 (추가 점검, `extra_timeband.csv`)
- 평균 차이 1분 초과·반복률 70% 이상인 버스→버스 자격 경로는 장애인 카드 93개(814개의 11.4%), 경로 카드 146개(1,152개의 12.7%)임 (추가 점검, `extra_magnitude.csv`)
- 9월 후보 가운데 8월에도 차이가 양수인 경로는 두 카드 모두 76%, 10월은 71%임. 9월 자격 경로 전체(기준선)는 장애인 카드 8월 65%·10월 62%, 경로 카드 58%·55%임. 장애인 카드 상위 10개의 평균 차이는 9월 2.70분에서 8월 2.13분, 10월 1.95분으로 줄어 9월 값에는 상위 선택에 따른 과대 추정이 일부 섞여 있음 (`holdout.csv`)

## 방법

- 비교 단위: 원자료 1행(같은 날·같은 1시간 시간대·같은 하차→승차 정류장 쌍). 대상 카드와 일반 카드가 함께 기록된 행을 '대응 행'으로 씀. 같은 키(날짜·하차ID·승차ID·시간대)가 여러 행으로 나뉜 경우(74일 6,399,241개 키, `data_quality.csv`의 dup_keys)도 합치지 않고 행 단위로 비교함
- 차이·가중치: 행마다 차이 = 대상 카드 평균 − 일반 카드 평균, 가중치 = 두 카드 건수 중 작은 값. 경로·기간 단위 차이는 이 가중치로 낸 가중 평균
- 품질 규칙: 카드 유형별 건수 합이 전체 건수와 다르거나(V1) 전체 평균이 유형별 평균의 건수 가중 평균과 1초 넘게 다른(V2) 행은 제외
- 경로유형: ID 길이로 정류장(9자리, B)과 역(4자리, S)을 나눠 BB/BS/SB/SS로 층화. BB는 같은 정류장·다른 정류장 두 층으로 나누고 두 층을 합친 버스→버스 값을 중심으로 봄
- 유효한 날: 경로마다 하루 가중치 합이 최소 가중치 5 이상인 날. 그날의 대응 행만 씀
- 자격 경로: 9월 유효한 날 7일 이상, 대상 카드 기록 30건 이상인 경로
- 후보 정렬: 자격 경로 중 경로 차이가 τ(주 설정 0분)보다 큰 경로를 후보로 두고 (차이, 기록 수) 두 축의 파레토 층 → 같은 층 안에서 차이 큰 순으로 정렬. 임의 가중 점수는 쓰지 않음
- 반복률: 유효한 날 가운데 하루 차이가 τ보다 큰 날의 비율
- 지표 정의(`docs/kpi_registry.yaml`)
  - A1: 같은 조건 비교 환승시간 차이(분). 사전등록 1차 지표
  - A2: 자격 경로의 반복률(%)
  - A3: 관측 규모와 표본 조건(대상 카드 기록 수·유효한 날 수·자격 경로 수)
  - A4: 현장 확인 우선 후보 목록(파레토 층 순)과 후보 수
  - A5: 대응·유효성 커버리지(품질 규칙 통과율, 대상 카드 기록 반영률, 정류장 위치 자료 연결률)
  - B1\~B3·C1\~C2: 정책 시행 뒤 측정할 운영·효과 지표 설계. 현재 값 없음
- 불확실성: 날짜 단위 군집 부트스트랩 1,000회(seed 20261019) 95% 구간. 추가 점검으로 경로 단위 군집 부트스트랩 구간도 계산
- 재현: 9월에 고른 후보의 차이를 8월·10월 1\~13일 자료로 다시 계산해 같은 방향(양수) 유지 비율을 9월 자격 경로 전체(기준선)와 비교하고 스피어만 순위상관을 봄
- 민감도: 최소 가중치 1·5·10, 유효한 날 5·7·14, 기록 수 10·30·50, τ 0·2·5분의 81개 조합과 품질 규칙 미적용 결과. τ는 반복률과 후보 기준에 함께 적용
- 대조군: 어린이·청소년 카드에 같은 계산을 적용
- 추가 점검(사전등록 외): 정류장 사이 거리별, 상한 기록 제외, 평일·주말, 시간대, 정류장 종류, 시설 이름 정류장 제외, 홀수일·짝수일 재현 등. 목록과 근거는 `docs/kpi_changelog.md`
- 사전등록: 정의는 `docs/kpi_registry.yaml`(v1), 초안 대비 변경·추가 점검·보고 층 추가 이력은 `docs/kpi_changelog.md`

## 시작하기

### 요구 사항

- Python 3.12
- git: 04가 `git rev-parse`로 현재 커밋을 읽어 산출물의 method_version에 기록함. git이 없으면 04가 멈추고 git 저장소가 아닌 곳(예: 압축파일로 받은 코드)에서 실행하면 커밋 칸이 빔
- Noto Sans KR 글꼴(06만 필요, https://fonts.google.com/noto/specimen/Noto+Sans+KR)
  - macOS: `~/Library/Fonts`에 있는 `NotoSansKR*.otf`·`NotoSansKR*.ttf`를 06이 직접 등록함
  - 그 밖의 위치·운영체제: 시스템 글꼴로 설치한 뒤 matplotlib 글꼴 캐시(`matplotlib.get_cachedir()` 폴더의 `fontlist-*.json`)를 지우고 06을 실행. 캐시가 남아 있으면 새로 설치한 글꼴을 찾지 못함
- 디스크 약 1GB(원자료 약 540MB, 일별 Parquet 약 380MB)
- 01 실행 시 인터넷 연결

### 설치

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

### 실행

저장소 최상위에서 아래 순서로 실행

```bash
.venv/bin/python scripts/01_download.py 2609 2608 261001 261002 261003 261004 261005 261006 261007 261008 261009 261010 261011 261012 261013 OA-15067:58 OA-15067:31 OA-21231:2:3
.venv/bin/python scripts/02_profile.py
.venv/bin/python scripts/04_kpis.py
.venv/bin/python scripts/05_robustness.py
.venv/bin/python scripts/07_extra_checks.py
.venv/bin/python scripts/06_figures.py
```

1. `01_download.py`: 원자료를 `data/raw/`에 받고 매니페스트에 기록. 인자 뜻은 아래 표. 이미 있는 파일은 덮어쓰지 않고 FAIL로 기록함
2. `02_profile.py`: ZIP 안 일별 CSV를 Parquet으로 바꾸고 스키마·품질 점검 결과를 `outputs/validation/`에 저장. 이미 있는 Parquet은 다시 쓰지 않음
3. `04_kpis.py`: 사전등록 지표 A1\~A5, 민감도 그리드, 8월·10월 재현 계산
4. `05_robustness.py`: 정류장 사이 거리별 버스→버스 차이(추가 점검)
5. `07_extra_checks.py`: 상한·요일·시간대·정류장 종류·시설 이름·재현 점검(추가 점검). 04 산출 표를 읽으므로 04 다음에 실행
6. `06_figures.py`: 04·05·07 산출 표로 그림 3종 작성

- 스크립트 번호 03은 결번임. 06은 04·05·07 산출 표를 모두 읽으므로 맨 마지막에 실행

| 01 인자 | 받는 파일 |
|---|---|
| `2609`, `2608` | 환승 자료 2026년 9월·8월 월별 ZIP |
| `261001` \~ `261013` | 환승 자료 2026년 10월 1\~13일 일별 ZIP |
| `OA-15067:58` | 서울시 버스정류소 위치정보(2026-09-02 기준) |
| `OA-15067:31` | 같은 데이터셋의 열 정의 문서(참고용, 코드에서 읽지 않음) |
| `OA-21231:2:3` | 서울시 정류장마스터 정보 첨부 자치구 정류장 코드 분류 |

- 실행 시간: 04·05·07을 이어서 실행할 때 실측 21.9\~31.2초(Apple M4 Pro 노트북, 메모리 48GB). 01·02·06은 측정하지 않음

## 재현성

- `requirements.txt`에 직접 의존성 버전 고정(duckdb 1.5.6, pandas 3.0.6, numpy 2.5.4, matplotlib 3.11.2, pyarrow 26.0.0, openpyxl 3.1.5, pytest 9.1.1). 전이 의존성은 고정하지 않음

- `kpi_results.csv`와 `kpi_summary_for_report.json`의 method_version(`registry_v1@<커밋>`)에 산출 때의 git 커밋을 기록함

## 한계

- 카드 유형은 카드 발급 분류이며 장애 여부·연령 집단 전체를 대표하지 않음
- 환승시간은 하차 태그부터 다음 승차 태그까지의 간격으로 추정함. 자료 설명에 단위가 없어 시간대별 최댓값(07\~20시 1,980, 그 밖 3,960)이 환승 인정시간 30·60분의 1.1배와 맞아 초 단위로 판단함(공식 정의 미확인)
- 환승시간에는 걷기·대기·차량 선택·짧은 용무가 섞여 있음. 차이는 관측값이며 시설 결함이나 차별의 증거가 아님
- 분석에 들어간 기록은 9월 장애인 카드 기록의 18.7%, 경로 카드 기록의 27.4%로 이용이 잦은 경로 위주임. 이동을 포기한 사람은 자료에 없음
- 역이 낀 환승: 장애인 카드는 대응 행이 적음(9월 역→역 9,443행, 버스→버스 344,300행). 경로 카드는 역→역 대응 행이 38,311행으로 적지 않지만 차이 방향이 버스→버스와 반대(-3.22분)여서 섞으면 전체 값이 음수가 됨. 그래서 정책 해석은 버스→버스에 한정함
- 경로별 순위는 달과 기준에 따라 흔들림. 버스→버스 자격 경로의 9월·8월 순위상관은 장애인 카드 0.43, 경로 카드 0.46임
- 시설 표시는 정류장 이름에 든 낱말 기준 근사이며 실제 시설 위치 자료가 아님
- 분석 기간은 2026년 8\~10월 74일뿐임
